# luminicalc-web
> **Status** In Development (v0.3.0)

## About
This project aims to teach the core foundations of web development using HTML5, CSS, and JavaScript.

## Features
- [x] Basic and minimalist calculator
- [x] Keyboard numbers
- [x] Logo
- [x] Light and dark themes added with local storage saving
- [x] More operator buttons(Root, Percentage, Parentheses and Exponent)
- [ ] More features coming soon...
